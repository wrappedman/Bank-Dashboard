# پیشخوان بانکی فارسی (RTL)

قالب/نمونهٔ کامل یک **پنل مدیریت کارت\u200cهای بانکی و عملیات بانکداری وب** بر پایهٔ طرح اولیهٔ موجود در برنچ `main`.

طرح اولیه (`index.html` / `style.css` / `script.js` در برنچ `main`) خوانده شد و این موارد عمداً حفظ شدند:

- چیدمان کلی: نوار بالا + نوار آیکون\u200cدار کناری + پنل سفید اصلی با گوشه\u200cهای ۳۰px + پنل کناری اعلان\u200cها
- کارت\u200cهای نمونه با رنگ\u200cهای پاستلی (`#fee4cb`, `#e9e7fd`, `#dbf6fd`, `#ffd3e2`, `#c8f7dc`, `#d5deff`) و رنگ\u200cهای تأکید مربوطه
- ساختار داخلی کارت: ردیف بالا (تاریخ/منوی بیشتر)، عنوان و زیرعنوان وسط\u200cچین، نوار پیشرفت، ردیف پایین با آواتارها و نشان pill
- دکمه\u200cهای تغییر نمای شبکه\u200cای/فهرستی، جستجو، تم تاریک، دکمهٔ `+` و پنل کشویی اعلان\u200cها

سپس همان پوسته به یک برنامهٔ بانکی فارسی تبدیل شد.

---

## اجرا

هیچ نصب، بیلد یا وابستگی\u200cای لازم نیست. کافی است پوشه را با یک سرور استاتیک سرو کنید (برای بارگذاری صحیح فونت\u200cها توصیه می\u200cشود):

```bash
cd Bank-Dashboard
python3 -m http.server 4173 --bind 0.0.0.0
# سپس http://localhost:4173 را باز کنید
```

باز کردن مستقیم `index.html` با `file://` هم کار می\u200cکند، ولی در بعضی مرورگرها فونت\u200cهای محلی با محدودیت CORS مواجه می\u200cشوند.

> تمام فایل\u200cها محلی\u200cاند: نه CDN، نه jQuery، نه فریم\u200cورک، نه تصویر خارجی، نه فونت اینترنتی. فقط `HTML + CSS + JS` خالص.

## ساختار فایل\u200cها

| فایل | توضیح |
| --- | --- |
| `index.html` | اسکلت رابط: `<html lang="fa" dir="rtl">`، هدر، سایدبار، پنل اصلی، پنل اعلان\u200cها، ناوبری موبایل، لایه\u200cهای مودال/توست/صفحه\u200cکلید/قفل |
| `style.css` | تمام استایل\u200cها: `@font-face` وزیرمتن، تم روشن/تاریک، RTL با ویژگی\u200cهای منطقی، رسپانسیو، حالت کیوسک، استایل چاپ |
| `data.js` | داده\u200cهای دمو و پیکربندی عملیات\u200cها (بدون منطق) |

| `assets/fonts/` | فونت وزیرمتن (Variable)، فونت آیکون، `icons.css` و متن مجوزها |

## امکانات

### ۱. منوی کاربر
کلیک روی **عکس/نام کاربر** منویی با «صفحهٔ پروفایل»، «تنظیمات»، «قفل کردن صفحه» و «خروج از حساب» باز می\u200cکند. بستن با کلیک بیرون یا `Esc`؛ `aria-expanded` و `role="menu"` رعایت شده است. خروج، صفحهٔ قفل با رمز نمایشی `1234` نمایش می\u200cدهد.

### ۲. فارسی و RTL کامل
- `lang="fa" dir="rtl"`، ویژگی\u200cهای منطقی (`margin-inline-start`، `inset-inline-*`، `border-inline-*`)
- اعداد و تاریخ\u200cها با `Intl` و تقویم هجری شمسی (`fa-IR-u-ca-persian`)
- فیلدهای عددی (شماره کارت، شبا، موبایل، رمز، OTP) با `dir="ltr"` ایزوله شده\u200cاند
- آیکون\u200cهای جهت\u200cدار در جای مناسب آینه شده\u200cاند
- **فونت وزیرمتن** (Variable، ۳ subset محلی) و **فونت آیکون** داخلی (نگاشت گلیف\u200cهای Font Awesome Solid به کلاس\u200cهای `ic-*`)

### ۳. واکنش\u200cگرا
- دسکتاپ/ویندوز: سایدبار راست + پنل اصلی + پنل اعلان\u200cها در چپ
- تبلت (≤۹۸۰px): سایدبار تبدیل به کشو، پنل اعلان\u200cها به صورت لایهٔ کشویی، ناوبری پایین
- موبایل (≤۵۶۰px): هدر دو ردیفه، کارت\u200cها تک\u200cستونه، ناوبری پایین ۵ گزینه\u200cای با دکمهٔ انتقال برجسته
- حالت `(pointer: coarse)` و کلاس `kiosk` اهداف لمسی را بزرگ می\u200cکنند

### ۴. مدیریت کارت\u200cها
تعریف/ویرایش/حذف کارت، تعیین **کارت پیشفرض**، مسدودسازی/رفع مسدودی، نمایش/پنهان\u200cسازی شماره، کپی شماره، کارت\u200cهای گرادیانی، موجودی، شبا و تاریخ انقضا.
اعتبارسنجی شمارهٔ ۱۶ رقمی با **الگوریتم Luhn** و شبا با **mod-97**.

### ۵. تنظیمات
- **اتصال به API بانک**: نشانی پایه، نسخه، `Client ID`، کد بانک، توکن (با نمایش/پنهان\u200cسازی)، timeout، هدر سفارشی، حالت «آزمایشی / زنده»، تست اتصال، SSL و ذخیرهٔ توکن
  - در حالت آزمایشی پاسخ\u200cها محلی شبیه\u200cسازی می\u200cشوند؛ در حالت زنده درخواست `fetch` واقعی با `AbortController` ارسال می\u200cشود (برای محیط واقعی به بک\u200cاند/پروکسی و تنظیم CORS نیاز است)
- **ذخیرهٔ اطلاعات مهم**: ذخیرهٔ تاریخ انقضا، شمارهٔ کامل کارت، CVV2، پوشاندن اطلاعات حساس و ذخیرهٔ تاریخچهٔ تراکنش\u200cها. این گزینه\u200cها *واقعاً* روی `localStorage` اثر می\u200cگذارند (مثلاً با خاموش کردن انقضا، هنگام ذخیره مقدار آن حذف می\u200cشود و در کارت به\u200cصورت `•• / ••` دیده می\u200cشود)
- **نمایش و کیوسک**: تم، اندازهٔ قلم، خروج خودکار، حالت کیوسک، صفحه\u200cکلید لمسی، اعلان\u200cها، چیدمان فشرده، تمام\u200cصفحه
- **داده\u200cها**: پشتیبان JSON، خروجی CSV، بازیابی پشتیبان، چاپ گردش حساب، بازنشانی کامل

### ۶. عملیات\u200cهای بانکی (همه با دادهٔ دمو)
| عملیات | توضیح |
| --- | --- |
| دریافت موجودی | استعلام با پاسخ شبیه\u200cسازی\u200cشدهٔ API، ماندهٔ قابل برداشت، مبلغ مسدود، کد پیگیری |
| انتقال وجه (کارت به کارت) | مبدأ/مقصد، مبلغ، توضیحات، مقصدهای ذخیره\u200cشده، تأیید با OTP، کسر موجودی، رسید |
| حوالهٔ بانکی | پایا/ساتنا/داخلی/بین\u200cبانکی، شبا، گیرنده، بانک مقصد، رسید و فهرست حواله\u200cها |
| پرداخت قبض | شناسهٔ قبض/پرداخت، قبض\u200cهای نمونه، دکمهٔ درج اطلاعات دمو |
| شارژ موبایل | اپراتور، شماره، مبلغ، شارژهای اخیر |
| صورتحساب و گردش حساب | فیلتر نوع/کارت/وضعیت، جستجو، نمودار هفتگی، CSV و چاپ |
| مسدودسازی کارت | دلیل، ثبت وضعیت کارت، رسید |
| تغییر رمز کارت | رمز دوم/اصلی، تکرار رمز، OTP |
| استعلام شبا | اعتبارسنجی mod-97 و نمایش کد بانک |
| بستهٔ اینترنت / پرداخت قسط / دسته\u200cچک | فرم، تأیید، رسید و فهرست دمو |

همهٔ عملیات دارای **مراحل ۳\u200cگانه** (اطلاعات ← تأیید/OTP ← رسید)، **رسید قابل چاپ**، کپی شمارهٔ پیگیری و ثبت تراکنش/اعلان هستند. کد OTP نمایشی: `1234`.

هر عملیات در **پنجرهٔ شناور خودش** باز می\u200cشود و چند پنجره می\u200cتوانند هم\u200cزمان باز بمانند؛ دکمهٔ کمینه\u200cکردن، پنجره را به نوار پایین صفحه منتقل می\u200cکند (چند پنجرهٔ کمینه\u200cشده کنار هم قرار می\u200cگیرند) و با کلیک روی نوار عنوان آن دوباره باز می\u200cشود.

### ۷. صفحهٔ اصلی
۱۳ کارت عملیاتی با همان ظاهر کارت\u200cهای نمونه، **تگ\u200cهای متفاوت** (پرکاربرد، سریع، امن، اضطراری، بدون کارمزد، جدید، …)، نوار سهم استفاده، نشان pill و منوی «⋯» (افزودن به منتخب\u200cها / جزئیات / باز کردن). جستجوی سراسری، نمای شبکه\u200cای/فهرستی، نوار کارت پیشفرض، آمار و آخرین تراکنش\u200cها.

### ۸. کیوسک لمسی
- حالت کیوسک: فونت و دکمه\u200cها بزرگ\u200cتر، `--tap: 58px`، جدول\u200cها خواناتر
- **صفحه\u200cکلید عددی روی صفحه** برای مبالغ، شماره\u200cها و OTP؛ فقط هنگام فوکوس فیلدهای عددی در صفحه\u200cی باز نمایش داده می\u200cشود (هنگام قفل/ورود دوباره به\u200cطور خودکار باز نمی\u200cشود) و کاملاً با تنظیم «صفحه\u200cکلید لمسی عددی» در تنظیمات روشن/خاموش می\u200cشود
- حذف وابستگی به `hover`، `touch-action: manipulation`، `focus-visible`، `safe-area-inset`
- **خروج خودکار** پس از عدم فعالیت + هشدار ۳۰ ثانیه قبل + قفل صفحه
- دکمهٔ تمام\u200cصفحه، چاپ رسید، عملیات تأییدشده با OTP

### ۹. سایر
پروفایل کاربری (ویرایش، آپلود آواتار محلی، سطح امنیت، تاریخچهٔ ورود)، پشتیبانی/FAQ/گزارش مشکل، اعلان\u200cها با علامت خواندن، تم تاریک، توست\u200cها، مودال\u200cها، میانبر `Ctrl+K`، `Esc`، لینک پرش به محتوا، خروجی/ورودی JSON و CSV، اعتبارسنجی فرم\u200cها و پیام\u200cهای خطا.

## نکات امنیتی / دمو

- **تمام داده\u200cها ساختگی\u200cاند**؛ هیچ تراکنش واقعی، هیچ ارتباط بانکی و هیچ ارسال اطلاعاتی به سرور انجام نمی\u200cشود.
- ذخیره\u200cسازی فقط در `localStorage` همان مرورگر/دستگاه است. کلیدها، CVV2 و تاریخ انقضا طبق تنظیمات «ذخیرهٔ اطلاعات مهم» ذخیره یا حذف می\u200cشوند (پیشفرض: فقط ۴ رقم آخر شمارهٔ کارت).
- برای اتصال به API واقعی، حالت «زنده» را فعال کنید؛ در عمل باید توکن را روی بک\u200cاند امن نگه داشت و درخواست\u200cها را از طریق پروکسی هم\u200c Origin ارسال کرد (CORS).
- رمز ورود نمایشی `1234` است.
