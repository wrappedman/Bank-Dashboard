# مجوز فونت‌ها و آیکون‌ها

همهٔ فونت‌ها به صورت **محلی** در همین پوشه قرار دارند و برنامه برای نمایش هیچ درخواستی به CDN یا سرویس خارجی ارسال نمی\u200cکند.

| فایل | منبع | مجوز | فایل متن مجوز |
| --- | --- | --- | --- |
| `vazirmatn-*-wght-normal.woff2` | [Vazirmatn](https://github.com/rastikerdar/vazirmatn) (Saber Rastikerdar) — بستهٔ npm `@fontsource-variable/vazirmatn@5.3.0` | SIL Open Font License 1.1 | `LICENSE-Vazirmatn.txt` |
| `fa-solid-900.woff2` | [Font Awesome Free 7.3.1](https://fontawesome.com) (Fonticons, Inc.) — بستهٔ npm `@fortawesome/fontawesome-free@7.3.1` | فونت: SIL OFL 1.1 · آیکون\u200cها: CC BY 4.0 · کد: MIT | `LICENSE-FontAwesome.txt` |
| `icons.css` | نگاشت سفارشی گلیف\u200cها به کلاس\u200cهای `ic-*` که در این پروژه نوشته شده است | تابع مجوز فونت بالا | — |

نکته: `icons.css` فقط یک فایل CSS ساده و دست\u200cنویس است که کدپوینت گلیف\u200cهای موردنیاز را نگاشت می\u200cکند؛ هیچ فایل CSS/JS متعلق به Font Awesome در زمان اجرا بارگذاری نمی\u200cشود. آیکون\u200cها صرفاً به\u200cصورت **فونت آیکون** استفاده شده\u200cاند (نه SVG، نه کتابخانهٔ JS).
